# Support policy

IOBusMonitor is MIT licensed. The public repository is free to use, fork and modify under the license terms.

## Free support

Use GitHub Issues for:

- reproducible bugs,
- build failures,
- documentation errors,
- feature proposals,
- protocol compatibility reports.

A good issue includes:

- app version or commit SHA,
- Windows version,
- protocol type,
- device model if public,
- steps to reproduce,
- expected result,
- actual result,
- log excerpt if available.

## Paid/custom support

Suitable paid work:

- custom device/register templates,
- new protocol adapter,
- on-site commissioning assistance,
- branded internal release package,
- CSV/report/export customization,
- training for maintenance teams,
- priority bug fixing,
- integration with plant-specific storage/reporting workflows.

## Boundaries

IOBusMonitor is a monitoring and troubleshooting tool. It is not a certified safety system, SCADA replacement, or guaranteed historian.
