# Paid services / custom integration examples

This file is a positioning draft. Keep it factual and only publish what you are willing to deliver.

## Service packages

### 1. Device template package

Deliverable:

- predefined Modbus/S7 device definitions,
- register/address mapping,
- units and scaling formulas,
- short validation document.

Best for:

- integrators who repeatedly commission the same device family.

### 2. Custom protocol or device adapter

Deliverable:

- adapter implementation,
- configuration UI changes,
- smoke tests,
- sample configuration,
- documentation.

### 3. Deployment package

Deliverable:

- branded portable ZIP or installer,
- predefined configuration,
- versioned release notes,
- short admin guide.

### 4. Reporting/export package

Deliverable:

- CSV/Excel export shape,
- filtered history export,
- plant-specific naming conventions,
- automated archive export if needed.

### 5. Training and support

Deliverable:

- remote walkthrough,
- user guide for technicians,
- troubleshooting checklist,
- support window for rollout.
