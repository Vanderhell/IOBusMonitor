# Product positioning

## One-line positioning

Portable Windows field-bus monitor for commissioning and troubleshooting Modbus TCP/RTU and Siemens S7 data.

## Strong use cases

- Commissioning a machine and watching register values live.
- Temporary logging during diagnostics.
- Checking if sensors/PLC addresses produce expected values.
- Exporting short-term evidence to CSV/SQLite.
- Providing a simple tool to maintenance without deploying a SCADA.

## Weak/bad use cases

- Certified historian.
- Safety-critical monitoring.
- Alarm management system.
- Multi-user web dashboard.
- Full SCADA replacement.
- Large enterprise data platform.

## Main differentiator

Small, portable, open-source, technician-oriented Windows app with multiple industrial protocols and local archives.

## What must be proven

- Fresh install works.
- Demo mode works.
- Polling is stable.
- Data is not silently misclassified.
- History is fast enough for realistic archive sizes.
- UI looks trustworthy.
