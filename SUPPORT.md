# Support

## Scope

IOBusMonitor is MIT licensed and publicly available. The repository supports both free issue-based collaboration and paid custom work outside the repository.

## Free Support

Use GitHub Issues for:

- reproducible bugs,
- build failures,
- documentation errors,
- feature proposals,
- protocol compatibility reports.

A useful issue should include:

- app version or commit SHA,
- Windows version,
- protocol type,
- device model if it can be shared,
- steps to reproduce,
- expected result,
- actual result,
- relevant log excerpt if available.

## Paid / Custom Work

Typical custom work that fits this project:

- device-specific templates,
- protocol adapters,
- internal release packaging,
- branded builds,
- CSV/report export changes,
- technician onboarding,
- priority troubleshooting on plant-specific deployments.

Examples and scope details are documented in [docs/SERVICES.md](docs/SERVICES.md).

## Boundaries

IOBusMonitor is a monitoring and troubleshooting tool. This document does not present it as a certified safety system, a SCADA replacement, or a guaranteed historian.
